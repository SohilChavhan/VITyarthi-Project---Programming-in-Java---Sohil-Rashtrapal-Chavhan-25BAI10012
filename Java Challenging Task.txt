Scenario:
You are developing the onboarding module for an e-commerce platform. When a merchant uploads a new item, the backend receives raw text inputs for the product's title, its unique inventory tags, and its category. You need to sanitize, validate, and format this metadata before saving it to the database.

Task:
Apply suitable Java String methods to perform the following operations:
1. Accept the product's full title, raw metadata tag, and category name.
2. Find and display the length of the product title.
3. Convert the product title into both uppercase (for shipping labels) and lowercase (for URL routing).
4. Extract and display the first word (brand/primary identifier) from the full product title.
5. Check whether the raw metadata tag contains a specific hash character (#) to verify it is an active system tag.
6. Replace spaces in the product title with underscores (_) to automatically generate a clean web-friendly URL slug.
7. Compare the merchant-entered category name with "Electronics" without considering case sensitivity.
8. Display the product title in reverse order (used as a simple mock hashing mechanism for temporary system keys).

--------------------------------------------------------------------------------
JAVA SOLUTION:
--------------------------------------------------------------------------------

import java.util.Scanner;

public class ProductOnboarding {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // 1. Accept inputs
        System.out.print("Enter Product Full Title: ");
        String productTitle = scanner.nextLine();

        System.out.print("Enter Raw Metadata Tag: ");
        String metadataTag = scanner.nextLine();

        System.out.print("Enter Category Name: ");
        String categoryName = scanner.nextLine();

        System.out.println("\n----------------- PROCESSING RESULTS -----------------");

        // 2. Length of the product title
        int titleLength = productTitle.length();
        System.out.println("1. Product Title Length: " + titleLength);

        // 3. Uppercase and Lowercase conversion
        String upperTitle = productTitle.toUpperCase();
        String lowerTitle = productTitle.toLowerCase();
        System.out.println("2. Uppercase (Shipping Label): " + upperTitle);
        System.out.println("   Lowercase (URL Routing): " + lowerTitle);

        // 4. Extract first word (brand/primary identifier)
        String firstWord = "";
        int firstSpaceIndex = productTitle.trim().indexOf(" ");
        if (firstSpaceIndex != -1) {
            firstWord = productTitle.trim().substring(0, firstSpaceIndex);
        } else {
            firstWord = productTitle.trim(); // single word title
        }
        System.out.println("3. First Word (Brand Identifier): " + firstWord);

        // 5. Check if raw metadata tag contains '#'
        boolean hasHash = metadataTag.contains("#");
        System.out.println("4. Is Active System Tag (contains '#'): " + hasHash);

        // 6. Replace spaces with underscores for web-friendly URL slug
        String urlSlug = productTitle.replace(' ', '_');
        System.out.println("5. Web-Friendly URL Slug: " + urlSlug);

        // 7. Compare category with "Electronics" (case-insensitive)
        boolean isElectronics = categoryName.equalsIgnoreCase("Electronics");
        System.out.println("6. Is Category 'Electronics' (Case-Insensitive): " + isElectronics);

        // 8. Display product title in reverse order
        String reversedTitle = new StringBuilder(productTitle).reverse().toString();
        System.out.println("7. Reversed Title (Mock Hash Key): " + reversedTitle);

        scanner.close();
    }
}
